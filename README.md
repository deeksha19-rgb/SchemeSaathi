# SchemeSaathi

**A Multilingual Government Scheme Intelligence Assistant**

SchemeSaathi is an AI-powered assistant designed to help citizens understand government schemes, eligibility criteria, required documents, and application procedures.

## Planned Features

- Multilingual support: Kannada, English and Hindi
- Government document ingestion
- Hybrid search (semantic + keyword retrieval)
- RAG-based question answering
- Evidence-based answers with source citations
- Eligibility assistance using AI agents
- FastAPI backend and Streamlit frontend

## Technology Stack

- Python
- LangChain / LangGraph
- ChromaDB
- BGE-M3 embeddings
- Groq LLM API
- FastAPI
- Streamlit

## Project Status

Currently under development.

## Disclaimer

SchemeSaathi provides informational guidance based on available government sources. It does not provide official eligibility approval or replace government authorities.
